# Conxius Protocol Implementations

This directory documents the specific implementation details, standards, and research for Bitcoin-native and second-layer protocols supported by Conxius.

Per-protocol implementation status and evidence bounds are recorded in the
[Implementation Registry](IMPLEMENTATION_REGISTRY.md). Treat that registry as the
authoritative source; a protocol is not live until the registry says so.
