## 2. Org Sub-Repo Architecture & Live Cloud Resource Mapping

### Sub-Repo Boundary Definition
- **`conxius-wallet` (This Repo)**: Tier 1 Production Core client app. Owns UI, native Android managers (`android/core-bitcoin`), client-side protocol services (`services/`), and local enclave storage.
- **`lib-conxian-core`**: Upstream core cryptographic and protocol libraries. Client application consumes packaged releases rather than modifying sub-project code directly from the wallet repository.
- **`conxian-gateway`**: Upstream backend event bus and B2B portal routing infrastructure.
- **`conxian-nexus`**: Sovereign state layer providing block height, state proofs, and mainnet sync validation.
- **`conxius-platform`**: Sibling full-stack server and cloud blueprint repository. Baseline failures in `conxius-platform` (CON-1230, CON-1231, CON-1232) are platform-repo issues and do not contaminate local wallet builds.
